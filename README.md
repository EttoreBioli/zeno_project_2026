
# Zeno AUV: Autonomous Navigation & Path Planning 

This repository contains the source code, simulation models, and documentation developed for the final project of the **Underwater Systems** course (Master's Degree in Robotics and Automation Engineering, University of Pisa, A.Y. 2025/2026).

## Project Overview
The objective of this project was to design and implement a complete architecture for **perception, path planning, and control** of the Autonomous Underwater Vehicle (AUV) *Zeno*, operating in an unstructured and a priori unknown environment. 
The system was designed using a hybrid digital-real approach: missions were executed on the surface of the *Laghetti di Campo* (San Giuliano Terme, Italy), while perception data was generated in real-time by a simulated digital twin.

The integrated system is capable of:
1. **Systematic Exploration**: Covering a designated area to maximize sensor footprint.
2. **Target Detection**: Identifying and localizing acoustic targets using Side Scan Sonar (SSS) and Forward Looking Sonar (FLS).
3. **Autonomous Navigation**: Planning and executing optimized trajectories to visit valid targets while strictly avoiding obstacles.

## Key Methodologies & Algorithms

### Path Planning & Obstacle Avoidance
* **A* Algorithm on Occupancy Grid**: Replaced stochastic approaches (RRT) with a deterministic A* search on a discretized grid ($0.5 \times 0.5$ m). This ensured global optimality, repeatability, and the generation of smoother, more energy-efficient paths (straight lines favored by applying a directional penalty cost).
* **TSP Greedy for Target Sequencing**: The Traveling Salesperson Problem (TSP) for multiple targets was solved using a Greedy (Nearest Neighbor) heuristic, utilizing the actual A* path costs rather than simple Euclidean distances, significantly reducing computational time while ensuring operational efficiency.
* **Waypoint Injection via Grid Sampling**: To ensure complete acoustic coverage of blind spots left by the primary route, "virtual targets" were generated dynamically by sampling the uninspected areas (Grid Sampling) and inserted into the navigation queue.

###  Guidance & Control System
A robust **cascade control architecture** was developed to handle the nonlinear, underactuated dynamics of the AUV:
* **Phase 1 - Coverage (Segment-Bounded Line-of-Sight)**: A custom Line-of-Sight controller was developed to minimize Cross-Track Error along straight transects. A dynamic Look-Ahead distance was implemented to ensure aggressive recovery from wind/current disturbances without inducing oscillations near the track.
* **Phase 3 - Tactical Navigation (Multi-Segment Look-Ahead)**: To smoothly follow the complex, obstacle-avoiding paths generated by A*, the controller was upgraded to anticipate corners. The virtual target "slides" across waypoints, allowing the AUV to cut corners efficiently.
* **Adaptive Speed Modulation**: A quadratic velocity profile was implemented to dynamically reduce surge speed based on yaw error, cross-track error, and proximity to sensitive targets (buoys), ensuring precise flyovers ($\sim 0.5$ m tolerance).

##  Technologies Used
* **ROS (Robot Operating System)**: Core middleware for node communication, telemetry handling, and simulation.
* **Python / C++**: Development of planning and control nodes.
* **MATLAB**: Used for preliminary control logic validation and post-mission telemetry analysis.

##  Results & Field Testing
The architecture was successfully deployed and tested on the physical Zeno AUV in open water. Despite significant environmental disturbances (wind gusts and surface currents) and initial GPS uncertainties, the control system proved highly robust. The AUV successfully explored the area (99.98% coverage), avoided all mapped obstacles, and intercepted all targets within the strict 20-minute mission time limit.
